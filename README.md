# Temporada

Static site showing which fruits and vegetables are in season in Argentina, month by month (southern hemisphere, Buenos Aires / Pampas reference). Spanish and English names.

No build step for the site. Open `index.html` or serve the folder.

## Data

`data/produce.js` is generated by `python3 scripts/build_data.py`. Edit the source lists in that script, not the generated file.

- **Source A (monthly):** InfoAgro / inspiracioneco calendar, republished by AgroRuralNoticias on 2020-07-18, which says it was compiled from public INTA documents. Secondary source; repeated months (Dec, Mar, Jun) are merged.
- **Source B (seasonal, approximate):** argentina.gob.ar, *Más Frutas y Verduras* and *Cuatro Estaciones*. Used only for items missing from A; seasons are mapped to months coarsely (marked `~` in the UI).

Limits: one national/Pampas-style list, no regional variation, no peak-season marking, English names are translations added by the maintainer. Better primary sources (INTA, Mercado Central de Buenos Aires) would improve it.
